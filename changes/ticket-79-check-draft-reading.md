### Fixed

- `check-draft`'s `numbers` check skips only the comments and fenced code that the rendered reading drops, so it reads every number a reader sees. A `<!--` that opens no comment, in a code span or fenced code, escaped as `\<!--`, or the start of the empty comment `<!-->`, used to hide every number up to the next `-->` anywhere later in the file, while the draft showed them, so a draft with an untraced number there could be released. A comment never closed, which the `markdown` check refuses, now hides the rest of the file from `numbers` as from the other checks, as it would render. Fenced code is taken from the same reading; it differs from before only for a fence the `markdown` check refuses.
- `check-draft`'s `questions` check no longer accepts a question that `methodology.md` holds only in an image's text, which shows only when the image fails to load, or to a screen reader. The check reads an image as the picture it shows, so a question cannot run across one either. The other checks still read an image's text.
- `references/helpers.md`, the `check-draft` help text, and the design record say which comments `numbers` skips and that the `questions` check leaves image text out; `helpers.md` also says that a fence or comment never closed hides the rest of the file rather than being read as text.
