# Microsoft 365 Copilot assembly

In the Microsoft 365 Copilot app, use the PowerPoint agent to build the deck from `findings.md` and the `chart-*.csv` files under `deck-rules.md`, and improve its presentation, while preserving every slide, claim, value, qualification, and caveat. This file adds only what is specific to PowerPoint and the Copilot app; `deck-rules.md` governs everything else.

## Attaching the files

The requester opens a Copilot app chat, adds the PowerPoint agent, attaches `findings.md`, every `chart-*.csv`, `methodology.md`, `deck-rules.md`, and this file, `m365-assembly.md`, and sends this prompt:

> Build a PowerPoint deck from findings.md and the chart files, following deck-rules.md and m365-assembly.md.

Datasets, and `methodology-note.md` when the package has one, travel beside the deck and are not attached. The package's `START-HERE.md` repeats this list and prompt.

## PowerPoint specifics

- **Sections.** The **Findings** section of the deck is a PowerPoint section holding one slide per `###` finding. The **Appendix**, when the outline has one, is a PowerPoint section that opens with its divider slide.
- **Headlines.** Each headline goes in the slide's title placeholder.
- **Native charts.** Build each chart as a native, editable PowerPoint chart whose data is its chart file, not as a picture. When a chart cannot be built as a native chart from its file, or its data does not match the file, say so to the requester and name the slide, so they can insert the chart in PowerPoint and paste the file's values into its data.
- **Tables.** Build each Table form as a PowerPoint table.
- **Accessibility.** Run PowerPoint's accessibility checker.

## Before handing back

Confirm, besides what `deck-rules.md` lists: every chart native from its file, and the accessibility checker clean.
