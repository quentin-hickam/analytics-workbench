# Results tables

Use a compact Markdown table for chat, whether standalone or accompanying a chart. A standalone table requires no plotting libraries, style setup, image, or image checklist.

- Keep chat tables to about six columns and fifteen rows; split or summarize larger results and link the full result.
- Right-align numeric columns (`---:`), put units in headers, use thousands separators, and give each percentage column one decimal precision throughout. Use the same rounding as the narrative and any companion figure.
- Order rows by the comparison (descending value or time), include n with rates, and mark caveated cells with footnotes explained directly under the table.
- For a document, copy the rendered table and verify the paste; raw Markdown pasted into desktop Word stays literal text. Package tables reach Word through the M365 assembly.

Before delivery, verify displayed values against the analytical result, units and denominators are clear, caveats are attached to affected cells, and any summarized or omitted results are explained with a link to the full result.
