## Current findings

Status is provisional, supported, or superseded. For a flagged finding, status is `revalidation-needed` with its prior status visible, for example `revalidation-needed (was supported)`.

The table is rendered from `findings.json`. Change the table only through `run.py` and `python3 src/awb.py state` commands. `run.py` writes one row for each result. The Evidence cell of that row links its evidence file, for example `[r-003](evidence/r-003.json)`. `python3 src/awb.py state finding` changes the wording, status, or caveat of the row. Commits and checksums are in the evidence file.
